# Practice folder for Chapter 13

Each lesson in Chapter 13 ends with a short "Try it". This folder holds its files. Chapter 13's lab has its own zip, so you can change anything here.

- Open this folder, `brightline-practice-ch13`, in your coding agent.
- `AGENTS.md` tells the agent how to work with you. Lesson 13.1 shows you how to set your language in it.
- There is one folder for each lesson, such as `13-1`. Each holds the same program in TypeScript and in Python.

Every name, number and company here is invented.
