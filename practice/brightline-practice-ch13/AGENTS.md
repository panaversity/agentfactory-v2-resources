# Practice for Chapter 13

I am learning to read code, one small file at a time.

My language is: TypeScript

Each lesson has a folder, such as 13-1. "The file" means the file named try in that folder, in my language. When I ask for a new file, make it in my language.

Run a TypeScript file with `node`, and a Python file with `uv run python`. The tests in 13-11 run with `node --test try.test.ts` for TypeScript, and `uvx --with pytest pytest test_try.py` for Python. Check types with `npx -y -p typescript tsc --noEmit <file>` for TypeScript, and `uvx pyright <file>` for Python. These fetch the checker from the internet the first time, so tell me before you run one.

Rules:

- Run a file only when I ask you to.
- Do not explain code or output until I ask.
- Change only what I ask you to change.
- Do not install anything unless I say yes.
