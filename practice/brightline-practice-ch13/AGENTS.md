# Practice for Chapter 13

I am learning to read code, one small file at a time.

My language is: TypeScript

Each lesson has a folder, such as 13-1. "The file" means the file named try in that folder, in my language. When I ask for a new file, make it in my language.

Run a TypeScript file with `node`, and a Python file with `uv run python`. The tests in 13-9 run with `node --test try.test.ts` for TypeScript, and `uvx --with pytest pytest test_try.py` for Python. Check types with `npx -y -p typescript tsc --noEmit` for TypeScript, and `uvx pyright` for Python.

Rules:
