# Practice folder for Chapter 12

The short practice exercises on the page "12.8 How today's tools realize it" use this folder. Chapter 12's lab has its own zip, so you can change anything here.

- `brightline-ap/` is the project. It is the only folder you open in a coding agent.
- `live-export/` stands for a file that must not leave the company. The practice for lesson 12.2 asks why you do not open the folder above it.

Every name, number and company here is invented, and the account numbers are not real.
