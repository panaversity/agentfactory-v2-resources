# Practice files for Build Something

The **Try it** tasks in the section "Build Something" of *Claude and ChatGPT 2.0* use these three files. Each task tells you which file it needs.

It is Monday, October 12, 2026. Last Friday, Brightline's managers met to review the third quarter of the year (Q3): July, August and September. These files are what the meeting left behind.

- `q3_review_notes.txt` holds the notes someone typed during the meeting. Nobody has tidied them. The Docs, Slides, Design and Whiteboard pages use it.
- `budget_actual_q3.csv` lists eight departments. For each month it gives the budget (what the department planned to spend) and the actual (what it spent). The Sheets and Data pages use it.
- `brand_note.txt` gives Brightline's colors and fonts. The Design page uses it.

The Data page also has a longer task. It uses Google's sample data, not a file from this folder.

Brightline Wholesale Supply is a made-up company. Every name and number here is invented for practice.
