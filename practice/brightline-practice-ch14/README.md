# Practice folder for Chapter 14

Each lesson in Chapter 14 ends with a short "Try it". This folder holds its files. Chapter 14's lab has its own zip, so you can change anything here.

- Open this folder, `brightline-practice-ch14`, in your coding agent.
- `AGENTS.md` tells the agent how to work with you. Lesson 14.1 shows you how to set your language in it.
- There is one folder for each lesson, such as `14-1`. Most hold the same program in TypeScript and in Python.
- `data/` and `scripts/` hold invented invoices and a small sample API that runs only on your own computer.

Every name, number, key and company here is invented.
