### Found by the checks while building

- **Row D10, the Python copy.** 100 pairs of calls at once: 108 of 200 answers were "The AP database is not reachable right now." Not a leak: the Python copy opened a connection for every call, 200 at once, past the database's limit of 100. Fixed by a limit of ten open connections per copy (`py/brightline_ap/db.py`). Then 0 of 200.
- **`--env` quietly used `dev`.** `process.loadEnvFile` keeps values already set, so a script started with `dev`'s file loaded and `--env ci` kept `dev`'s connection strings. Fixed: each environment's file now always wins (`scripts/lib/db.ts`), and no npm script loads a database file before the script chooses one.
- **A connection that times out while the database wakes** was reported as "not reachable". It is now the timeout message, which says to try again.
