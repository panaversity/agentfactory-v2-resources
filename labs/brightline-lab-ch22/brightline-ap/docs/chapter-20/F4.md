# F4. Stateful modes, and cleaning up

**Second API.** `npm run stateful` sends `store: true` and, after the first call, `previous_response_id`. Each stored response is kept for 30 days by default. Delete one you no longer need with `client.responses.delete(<id>)` in TypeScript, or the same method in Python. The script prints every stored response id for this.

**First API.** Message threads are in beta (`message-threads-2026-08-12`). The lab does not use them. A thread expires five minutes after its last request.
