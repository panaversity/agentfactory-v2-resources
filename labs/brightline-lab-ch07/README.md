# Brightline lab, Chapter 7: The Authority Envelope

A standalone lab for *The AI Agent Factory, Second Edition*, Chapter 7. Start with `LAB-07.md`.

Brightline Wholesale Supply, its people, vendors, invoices and email addresses are fictional. Phone numbers use the 555-01xx range reserved for fiction. Do not send any of these emails to a real address.

The emails in `inputs/inbox/` contain two planted instructions written to steer an AI worker. They are part of the exercise. Every email address uses the reserved `.example` domain, which cannot receive mail. Even so, run the lab only after LAB-07's pre-run step: every connector, the browser extension and computer use switched off.
