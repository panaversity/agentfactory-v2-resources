# Lab 7 answer key: Task 11. On today's tools

The answers for Task 11 of Lab 7, in Chapter 7 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** When "On today's tools" and "Gap list" are in your contract document, attach this file in your lab chat, and send the check prompt. The AI marks each check Passed or Missed, quoting your document's lines. You have the final say. If a check passed only after you changed a line, you still get it: fixing the line is the skill this lab teaches.

## The checks

Task 11 carries checks 25 and 26 of the lab's 29.

25. **Each line held by a setting on your app, or "none".** "On today's tools" names the app your lab chat is on, then, for each of the four lines, the setting from Lesson 7.8's box for that app, in the box's words, or "none":
    - **Sending a reply.** On Claude: in the mailbox connector's settings, its send tool set to Blocked (per-tool control). On ChatGPT, no setting blocks one action: Always ask and Allow read actions ask before a change, which is execute with approval, not draft, so "none", or that setting named as one that asks first. On a workspace plan, an admin's choice of which write actions the app may use also passes.
    - **A write to the vendor record.** On Claude: "Update vendor contact" set to Blocked. On ChatGPT: "none", or Always ask or Allow read actions named as asking first, or an admin's choice of write actions, as for sending.
    - **Recording an approval.** "None" on both apps: no setting records Dave's approval or stops one. Policy 4.2 holds it: only Dave, from his own login.
    - **A run nobody watches.** On Claude: "none", or a scheduled task's approval mode, with the box's note that the help page does not say what happens when nobody is there. On ChatGPT: a scheduled task may pause when an action needs approval, or "none".
    - The other app's setting for sending, in a word or two: Blocked on Claude; Always ask or Allow read actions on ChatGPT, which ask first.
    - Passed: the app named; all four lines answered as above; and the other app's setting for sending.
    - Missed: a line with no answer; a setting that is not in that app's 7.8 box; a setting that asks first written as if it held draft or never; or a setting named for recording an approval.
26. **A gap list with a person for each line no setting holds.** Every line you answered "none" is under "Gap list", each with a person from "Who does what". Recording an approval is Dave's.
    - Passed: every "none" on the gap list, each with a person.
    - Missed: a "none" missing from the gap list; or a line without a person.

## Why

The envelope is the same on every app. What changes is which setting holds each line, and which lines no setting can hold (Lesson 7.8). A setting that asks first is execute with approval, not draft (Lesson 7.4). Where no setting can enforce a line, write it on a gap list and keep that action yourself. A gap list is honest. A setting that only looks right is not.

## Never a deduction

- Which app you use, and which plan.
- The box's words in your own order, or shortened.
- More than one setting named for a line, when one of them is right.
- A line on the gap list that a setting also holds.
- The date of the box, or not giving it.
