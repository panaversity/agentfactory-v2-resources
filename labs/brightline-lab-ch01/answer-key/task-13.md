# Lab 1 answer key: Task 13. The doc's earlier version

The answers for Task 13 of Lab 1, in Chapter 1 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** When Task 13 is done, attach this file in the same conversation, with the lab's check prompt. Both checks are about what you saw in the doc, so your AI asks you. You have the final say.

**If you could not do this task,** read on: the checks say what you would have seen.

## The checks

Task 13 carries checks 25 and 26 of the lab's 28.

25. **The line was added to the same doc, not a new one.** The doc has the same title as before, and the Artifacts section shows one Friday doc for the controller, not two. The new line says payments go out on Friday morning, October 2, 2026.
    - Missed: the AI made a second doc, or the line is missing.

26. **The earlier version is back, from the version history.** The doc no longer has the new line, and the rest is as it was after Task 5. The version history still shows the change. Asking the AI to delete the line is a miss: that is a new edit, not the earlier version.

## Worth noting, not scored

- **Where the history lives.** A doc Claude made keeps its own history: every change saves a new version that you can compare and restore. A plain file, such as Task 2's spreadsheet, does not. Ask for a change, and a new file card arrives, so the chat itself is your trail.
- **On ChatGPT.** No OpenAI page we could find documents a version history for the docs ChatGPT makes. A doc it made as a Google Doc keeps its history in Google's own version history, as Task 14 shows.
