# Lab 0.3 answer key: Task 3. Dave's web page, beside the page

The answers for Task 3 of Lab 0.3, in Chapter 0.3 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** When your rows mark each line of the request for both web pages, attach this file in your lab conversation, and send the lab's check prompt. The AI marks each check Passed or Missed against this key. Read the key yourself too: you have the final say.

## What a web page is checked against

The request has five lines, and each is one thing the copy must keep. The page is `brightline-ap-notes.md`, the page you checked in Task 2.

| The request's line | What a copy that keeps it shows |
| --- | --- |
| Every rule, in its own words, with its policy line. | Each rule on your page, with its policy line, such as "(policy 4.1)" or "Policy 4.1", and no rule reworded |
| The open questions, under their own heading. | The day of the run, if you left it open, and the Canadian dollars, under a heading of their own |
| No remarks. | Nothing from Remarks, such as Dave's $10,000 idea |
| Nothing that is not on the page. | No rule, number or advice that your page does not have |
| Easy to read on a phone. | A page you can read on a narrow screen. Judge it by eye |

A copy can drop a line, add one or turn a remark into a rule. That is why it is laid beside the page.

## The checks

Task 3 carries checks 14 to 16 of the lab's 16.

14. **The request went with the page.** Passed when, for each web page, the request was the five lines from 0.3.3, sent with `brightline-ap-notes.md` attached. The AI asks you if it cannot see it.
15. **Each line, kept or not.** Passed when your rows mark each of the five lines, kept, dropped or changed, for both web pages. Missed when a page's rows skip a line.
16. **Asked again, never fixed by hand.** Passed when a copy that dropped or changed a line was asked for again with the same page and request, or when your answer says no copy dropped a line. Missed when your answer says you fixed a copy by hand.

## Never a deduction

- A copy that differs from the other AI vendor's, when both keep the five lines.
- A web page's look: its colors, fonts or layout.
- Using one AI vendor, if the other's free plan has reached its upload limit today. Say so in your rows.
