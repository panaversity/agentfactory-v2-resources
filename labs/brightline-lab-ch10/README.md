# Brightline lab, Chapter 10: keep the AP Worker running, on terms Dave can defend

Brightline Wholesale Supply is a wholesale distributor in Columbus, Ohio. In the first nine days of December 2026, four ordinary decisions went wrong: an early-pay list left out small suppliers, a schedule reached the auditors that Dave Kowalski, the controller, never saw, Maria, the office manager, uploaded the whole vendor file to her personal AI account, and a new clerk followed onboarding notes nobody owned. Dave's first answer was "Turn it all off." You help him keep the AP Worker running instead: you classify proposed uses, redact the vendor file, write one route-and-send spec for both AI vendors, check who the list left out, take down what must go, decide who signs, write the first-hour incident note, and make it last in a Governance Record, an interim AI policy and Draft 7 of the Role Contract.

This folder is standalone. It needs no files from other chapters. Start with `LAB.md`. Brightline Wholesale Supply, its people, vendors and invoices are invented. Tax IDs start with zeros so they can never be real, and phone numbers use the 555-01xx range reserved for fiction.
