Both are what the lab's wire tests capture from the real SDK clients, with long values shortened.

**The pinned models.** `claude-sonnet-5-5` and `gpt-6-luna`, set in `src/loop/config.json`. Both ids appear in the pinned SDKs' own model lists. Before the run, check each on its provider's models page, and that the OpenAI model supports function calling on the Responses API. Chapter 28 explains how to choose a model.
