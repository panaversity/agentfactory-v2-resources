# F0. The repository and its secrets

**Where to install the tools.** Node.js from nodejs.org (version 22.19 or later, the floor Lab 19 set; the test runner needs 22.12 or later). uv from docs.astral.sh/uv. Git from git-scm.com. The GitHub CLI from cli.github.com, then `gh auth login`. On Windows, WSL from Microsoft's "Install WSL" page (`wsl --install`). Python 3.12 or later comes with uv (`uv python install`).

**What the zip holds.** `brightline-lab-ch20.zip` holds `brightline-ap/`, a plain folder with no git history (Task 0 starts it and tags `lab20-start`), with the Chapter 20 files on top of what Chapter 19 left (see its README for the list), and `answer-key/` at the top of the zip, outside `brightline-ap/`. Never give the answer key to an agent.

| Path | What it is |
| --- | --- |
| `tools/ap-tools.json` | The four tools, defined once, in JSON Schema |
| `prompts/ap-worker.v1.md` | The worker's instructions, versioned |
| `src/loop/` | The loop in TypeScript: `claude.ts`, `openai.ts`, `tools.ts`, `limits.ts`, `trace.ts`, `stream.ts`, and `config.json` with `config.ts`, which reads it (Python reads the same `config.json` directly) |
| `py/brightline_ap/loop/` | The same in Python: `claude_loop.py`, `openai_loop.py`, `tools.py`, `limits.py`, `trace.py`, `stream.py` |
| `scripts/` (TypeScript), and `py/brightline_ap/ask.py` and `py/brightline_ap/experiments.py` (Python) | `ask`, `break`, `stateful` and `stream:demo`, in both languages |
| `py/brightline_ap/practice_connector.py`, `data/practice/` | The local practice connector and its data (route B) |
| `tests/`, `py/tests/`, `tests/fixtures/loop/` | The tests, and the recorded responses both languages replay |

**Secrets.** Nothing in this table is ever typed into a chat, printed or committed. Git ignores `.secrets/`.

| File | Holds | Made by |
| --- | --- | --- |
| `.secrets/anthropic.env` | `ANTHROPIC_API_KEY=` | You, in the Claude Console (F1) |
| `.secrets/openai.env` | `OPENAI_API_KEY=` | You, in the OpenAI dashboard (F1) |
| `.secrets/connector.env` | `CONNECTOR_URL=` and `CONNECTOR_TOKEN=` | Your agent, in Task 0 (F2) |

**Installing.** `npm ci` installs the pinned TypeScript packages from `package-lock.json`. For Python, `cd py && uv sync --locked` installs the versions pinned in `py/uv.lock`, among them `anthropic` 2.5.0, `openai` 3.46.0 and `mcp` 2.3.0. The lab's Python MCP client uses the `httpx2` library for HTTP, which the pinned SDKs also list in their requirements.
