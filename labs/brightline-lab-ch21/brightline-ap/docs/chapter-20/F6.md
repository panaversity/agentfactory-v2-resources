# F6. Ollama and an open model

1. Install Ollama from its own site for your operating system (on Windows, its Linux version, inside WSL).
2. Check that it listens on `127.0.0.1:11434` only. On a shared network, never set it to listen on every address.
3. Pull the pinned model: `ollama pull qwen3:8b` (several gigabytes: check the size on Ollama's model page).
4. `npm run ask -- --api open "…"` points the second API's client at `http://127.0.0.1:11434/v1/` with the placeholder key `ollama`, and sets `openModel: true`, which leaves out the `include` line that asks for encrypted reasoning (F3).
5. Stop the server when you finish. A local model costs no money per token, and its quality, speed and updates are yours to manage.
