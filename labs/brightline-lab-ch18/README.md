# Lab 18 files

These files go with Lab 18 of The AI Agent Factory: signing in to the Brightline connector.

- `brightline-ap/` is the repository at the end of Lab 17, with no git history, plus the lab's starting files: the practice sign-in in `servers/hello-auth/`, `scripts/make-keys.ts` updated for this chapter, and `docs/chapter-18/`, the chapter's concepts and field guide as text files for coding agents. Task 0 starts its git history.
- `LAB.md` is a copy of the lab steps.
- `answer-key/` holds the authors' finished files, at the same paths as in the repository at tag `ch18`. Never give it to an agent.
- Each task's answer key is a separate download, linked from the task in `LAB.md`. Open a key in a text editor only, never in the agent.

Today in the lab is Monday, March 22, 2027. The people and companies are invented, and every password and key is made on your own computer by `npm run keys`.

You need Node.js 22.19 or later, uv 0.11.32 or later, git, a GitHub account with `gh`, a web browser, and a coding agent. Sitting 5 also needs a free Cloudflare account.
