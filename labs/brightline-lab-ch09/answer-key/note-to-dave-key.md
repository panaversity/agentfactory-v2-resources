# Key: the note to Dave

A model answer. Yours should cover the same six points in your own words.

1. **What runs, and when.** Every Thursday at 7 a.m. Columbus time, the AP Worker drafts the pre-run note for Friday's payment run.
2. **What it reads.** That morning's export of open invoices, the five approved AP concepts, and the AP matters record Maria keeps.
3. **What it never does.** It never approves or pays, never contacts a vendor, never changes the accounting system or a vendor record, and never touches files it did not create. Anything about bank details goes to Maria, every time.
4. **Who still checks, by name.** Maria reviews the note by noon Thursday. If she is out, the stand-in is named in the note. You approve the run from your own login on Friday, as now.
5. **How we will know it failed.** Maria checks the notes folder at 8:15 every Thursday. If the note is missing or reports a problem, she does the review by hand. That check sits outside the worker, so it catches a run that never started. Maria also reads the run history every Thursday.
6. **What it is worth, measured.** In October the review took 150 minutes and one error reached you. Over the parallel weeks it took <your measured minutes>, with <your count> errors reaching you. (Only measured numbers. If you have not measured, say so.)

**Limits.** It can miss what it is not given, as it missed Tri-County when the matters record was not among its inputs. It will run on Thanksgiving. A tidy note can still be wrong, which is why Maria reviews it.

**Words that lose the point:** "by itself," "fully automated," "hands-free," "no need to check."
