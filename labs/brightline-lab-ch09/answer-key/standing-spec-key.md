# Key: standing spec

A spec earns full marks if a fresh run could follow it with no chat history. It must have each of these:

1. **Job.** Draft the pre-run note for Friday's payment run. Never approve it.
2. **Trigger.** Thursdays, 7:00 a.m., America/New_York (Columbus).
3. **Inputs.** The register file for this Thursday, the five concepts, and the SSoR record. If any of these is missing or dated wrong, stop the whole review and tell Maria. Do not guess.
4. **Read first.** Every open matter in the SSoR record, and every matter for a vendor with an invoice in the run.
5. **Rules.** Apply only the five concepts. Cite each by title and approval date. If no concept covers a case, say so and name Maria or Dave as the one who decides.
6. **State.** The register is the accounting system as of its export. The SSoR record is the latest known, not verified current. Recommend holds. Never state that a payment was made beyond what the register shows.
7. **Output.** The run list with due dates, totals by currency, approvals needed, recommended holds with the rule and matter, duplicates with both invoice numbers, questions for Maria. Saved to the notes folder with the run date in its name.
8. **Proposed SSoR entries.** At the end, a table of new entries, each with origin "inferred," for a person to check and add. It opens one matter for this week's payment run, and adds to any matter it acted on.
9. **Never.** Approve, pay, change a record in the accounting system, contact a vendor, decide a bank-detail or vendor-record request, or rename, move or delete any file it did not create.
10. **Exits.** Two kinds. A missing required input stops the whole review (item 3). A problem with one invoice or vendor, such as a bank-detail or vendor-record request or two records that disagree, stops only that item: mark it for Maria and carry on with the work it does not affect.
11. **Who reads it.** Maria by noon Thursday, or her named stand-in. Dave before Friday's run.
12. **How failure shows.** The run reports its own problems in the note. A check outside the run catches a run that never started: Maria checks the notes folder at 8:15 every Thursday, and if the note is missing she does the review by hand.

Ten of twelve, with items 3, 4, 9 and 10 present, is full credit.
