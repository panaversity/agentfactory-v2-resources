# Brightline lab, Chapter 9: Work That Runs Without You

A standalone lab for *The AI Agent Factory, Second Edition*, Chapter 9. Start with `LAB-09.md`.

Brightline Wholesale Supply, its people, vendors and invoices are fictional.

The SSoR record follows the design of SSoR (github.com/panaversity/ssor), which has no specification or code yet, so it is kept by hand. The concept files are simplified copies of Brightline's approved AP concepts. Their full format is in the KSoR project at github.com/panaversity/ksor. You do not need it for this lab.

Verified for the chapter on 7 October 2026.
