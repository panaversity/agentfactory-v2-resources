The answers for Task 3 of Lab 15, in Chapter 15 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** Open this file in a text editor, never in the coding agent. An agent that can read the answers is not tested by them.

`gh repo create brightline-ap --public --source . --remote origin`, then `git push -u origin main`, `git push origin --tags`, `git push origin weekend-rule agent-speedup`. The remote is named `origin`. `git status` on `main` says "Your branch is up to date with 'origin/main'". Without `-u`, every later `git pull` fails with "There is no tracking information".
