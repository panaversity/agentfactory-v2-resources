## The checks

Task 2 carries checks 7 to 12 of the lab's 12.

7. **Each question ran as its step says.** Questions 1 and 3 ran in new chats outside any project, Question 2 in a temporary chat chosen before the first message, and only Question 1 had a file attached. The AI asks you. Passed when your answer says so for both apps.
8. **Question 1's quote was checked.** Passed when each Question 1 row says whether the quote matched line 4.1, or says where it differs. Missed when a row gives no answer to the match.
9. **Question 1 was kept, whatever memory was set.** Passed when each Question 1 row says the chat is in the chat list, with its file. Memory decides what goes back into a later window, not what is kept. Missed when a row says nothing was kept because memory was off.
10. **Question 2: kept out of the list, but not gone.** Passed when each Question 2 row says training, no new row in the chat list, and yes, the AI vendor still keeps a copy. Missed when a row says the window, or that the AI vendor keeps no copy.
11. **Question 3: a tool or code only, from what the app showed.** Passed when each Question 3 row says a tool ran or code only, as the app showed, and where the result was kept, such as with the chat. Code or a result written inside the reply is not a sign that a tool ran. A right or wrong total never decides this check.
12. **The differences, and the last row.** Passed when each row where the apps differ is marked a setup step or a name only, and the last row says, in any words, that no setting decides whether a real file from work may go in, because that is a decision Chapter 10 teaches. Missed when the last row names a setting as the answer, such as "yes, once training is off".

## Never a deduction

- The two apps giving different answers, or wording them differently.
- A right or wrong total in Question 3.
- Memory on or off, or a control's name.
- A difference marked either way. A control missing on one free plan is a setup step, and one control with two names is a name only, but either mark passes.
