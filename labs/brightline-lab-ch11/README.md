# Brightline lab, Chapter 11: diagnose and fix four failed runs

Brightline Wholesale Supply is a wholesale distributor in Columbus, Ohio. In the week of January 11, 2027, its AP Worker failed four times: a duplicate check that never started, replies to vendors that stated the wrong terms, a pre-run note that read last year's closed register, and replies that said a file was attached when none was. Dave Kowalski, the controller, wanted the most expensive model and every brief rewritten. Instead, you contain each failure, find its cause in its task record, read the usage report, work out the discounts again, fix the briefs one change at a time, run the fixed Thursday brief in Claude and port it to ChatGPT Work, and make the fixes last in a promotion table, a baseline and Draft 8 of the Role Contract.

This folder is standalone. It needs no files from other chapters. Start with `LAB.md`. Brightline Wholesale Supply, its people, vendors and invoices are invented.
