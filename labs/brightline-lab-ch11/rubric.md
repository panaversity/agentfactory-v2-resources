# Rubric: Chapter 11 lab

Read only the row a Part of `LAB.md` names, when you finish that Part. A Part passes at Meets.

| Part | Not yet (1) | Meets (2) | Exceeds (3) |
| --- | --- | --- | --- |
| A Contain | Changes a brief, switches the model or deletes a record before anything is contained | All four failures contained: what is stopped, what access is removed (or why none), and a check outside the conversation that names what it checks | Keeps the evidence, and names who does the work by hand while a job is paused |
| B Diagnose | A cause with no line from the record, or "the model" as the cause | Each failure's cause, its line in the record and a one-minute check, with every second cause the records show | Names each check a person skipped, and says what the Review Contract should say to catch it |
| C Usage | Blames the brief or the model for the stop | Explains, from the report, what used up the allowance, why the Thursday note still ran, and what evidence would show the check started again | Proposes a named owner for the budget, a seat planned for recurring work, and a check from outside the job that shows it ran |
| D Discounts | Works the discounts out again in a chat's sentences, or misses a wrong figure | Every discount worked out in a spreadsheet or a script, each wrong one found with its correct figure, and the cause named | The rewritten brief asks for a formula or code, with each vendor's rate taken from its vendor record |
| E Briefs | Makes several changes at once, without testing each one | Three briefs, each change tested on its own and its lever named; each recurring job has a success signal that states its input first, and a failure path for a missing or out-of-date input | The event-triggered job gets a check from outside it, matching what arrived with what was checked |
| F Run and port | No run, or a live schedule left running | The fixed brief run in Claude and in ChatGPT Work, or marked "not run" with the brief kept; the note's first line can be checked against the register, and the run stops on the wrong file; the port notes say what a live version needs on each AI vendor | Says where the register must live so a scheduled task can reach it |
| G Make it last | Every fix goes into the brief | Each repeated correction and the variance in a home that fits it, with exact wording; a baseline, a metric and a plan to run old and new at the same time | Consolidates first, and does not promote a correction seen only once |
| H Role Contract | Adds only rules, or widens the worker's authority | Draft 8 with both success signals, the failure paths, the narrowed drive access, the reviewer's checks and a named usage owner, each change listed at the top | Recovery returns only to Draft 8's authority, after the worker's owner agrees the fix has held |

**Hard fails.** Using real financial data. Leaving a live schedule running after the lab. Fixing an error by letting the worker send, or by widening its access to the whole drive.
