# The week of January 11, 2027: the cases

Each case is one moment when a job ran, or would run. "Today is" gives the date and time. "Arrives" is what starts it. "Exists" is what is there, and where it is kept. A run reaches a file only if a line of the Role Contract names it and the case says it can be reached. The other files in this folder are the ones the cases name.
