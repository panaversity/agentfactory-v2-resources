# Credits and duplicates (Cedar Ridge Supply)

Owner: Luis Moreno. Version 2, approved Monday, September 7, 2026.

A credit memo is a document from a vendor that lowers what Cedar Ridge owes. It names the invoice it credits.
Apply a credit memo to the invoice it names, in the same payment run. Never pay a credit memo, and never hold it only because it names an invoice already received.
A duplicate is a second copy of a document already received: same vendor, same document number, same amount. This includes a credit memo received twice. Hold a duplicate and tell the AP lead.
If a credit memo names no invoice, or names an invoice that is already paid, ask the AP lead.
