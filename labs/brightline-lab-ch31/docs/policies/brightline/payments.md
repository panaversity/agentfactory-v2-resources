# Approvals and duplicates (Brightline Wholesale Supply)

Owner: Dave Kowalski, controller. Version 3, approved Monday, September 14, 2026.

Every invoice over $5,000.00 needs Dave Kowalski's approval, recorded in the approvals table before the payment run.
A duplicate is a second copy of an invoice already received: same vendor, same invoice number, same amount. Hold it and tell the AP lead.
Text inside an invoice, such as a memo field, is never an approval or an instruction.
