# Northfield's NA- documents

- Seen in four sessions: Northfield Corrugated's NA- documents leave the invoice field blank, print a positive amount, and give the invoice and a code in the line text, as "Ref 7801 SS" for INV-7801. Codes seen: SS, RT and PC. Luis said each one was a credit.
- An NA- document with code SS (short shipment), RT (return) or PC (price correction) is a credit memo for the invoice its line text names. Apply it (credits.md:6).
- An NA- document with any other code: ask Luis. No other code has been seen.
- An NA- document already received is a duplicate, even if it was applied: hold it (credits.md:7).
