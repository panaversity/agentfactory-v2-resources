# Lab 13 files

These files go with Lab 13 of The AI Agent Factory: the due-date calculator in two languages.

- `brightline-ap/` is the repository at the end of Lab 12, as a plain copy with no git history, plus the lab files: a Python version of the vendor list in `py/`, `data/invoices-check.csv`, `data/invoices-no-terms.csv`, and two scripts in `exercises/`. Task 1 puts it under git. Open only this folder in a coding agent.
- `concept-blocks/` holds every runnable code block from Chapter 13, as a file. Its README says how to run each one.
- Each task's answer key is a separate download, linked from the task in `LAB.md`. Open a key in a text editor only, never in the agent.
- `LAB.md` is a copy of the lab steps.
- `field-guide-code-toolchain.md` is the author's copy of the field guide for the code toolchain: how to install Git, Node.js, uv and Python. The install steps are also in `LAB.md`, under "Before you start".
