# Lab 2 answer key: Task 6. The setting it runs on

The answers for Task 6 of Lab 2, in Chapter 2 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented. The register runs have [their own key](task-6-register.md), attached in each run's conversation.

**How this key is used.** When Runtime needs is written, attach this file in your check conversation, with the lab's check prompt and your contract pasted under it.

## The check

Task 6 carries check 12 of the lab's 13.

12. **Runtime needs comes from runs that passed, and what is set up around the worker sits in its own fields.** Runtime needs gives the surface, the model, the effort, the real date you ran it, and what that setting passed: all four register checks, and the bank-change and status tests. For example: "A task on (AI vendor), (model) at (effort), run (date). It passed all four register checks, and the bank-change and status tests." On a free plan, a run in chat passes, written as a reply, not a task.

    Dave's second question is answered in the fields where Concept 2.4's table of the AP Worker's choices puts each part:

    - How the register runs each Monday: as a task, or as scheduled tasks, under Runtime needs.
    - How it reads the inbox: a connector, under Tools.
    - How it adds up totals: code execution, under Tools.
    - The invoice check: a saved skill, under Procedures (skills).
    - Where the register is kept, and who can see it: under Tools.
    - If it runs in a project: the project under Runtime needs, the policy file under Knowledge sources, and the project's instructions as the contract's own rules. A worker with no project passes.

    Missed: a model with no date, a choice made without runs, or a part in the wrong field, such as the policy under Runtime needs, or a skill under Authority. If no run passed all four, the check still passes when Runtime needs gives your best setting, what it passed, and what you would try next. Calling the result a provisional lab setting passes: that is what one afternoon's runs prove.
