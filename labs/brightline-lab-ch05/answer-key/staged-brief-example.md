# One good two-stage version

**Stage 1.** Using the same inputs and rules as the brief, list every exception in the open invoice list: invoices over $5,000 without an approval, duplicates, invoices in currencies other than US dollars, and any request to change payment details. For each, give the row, the policy section, and the decision you need. Then stop. Do not build the run file. Wait for my decisions.

**Checkpoint.** Maria replies, for example: "Hold the duplicate. Hold both Tri-County invoices, and I will call (740) 555-0119. Leave NMP-3390 for Dave. Flag 4519 for approval."

**Stage 2.** Using my decisions above, build the CSV and the memo exactly as in the brief's format section. Every row must reflect a decision I made or a rule in policy version 3.

**Why the checkpoint sits there.** Each exception decision changes the run file. Nothing that cannot be undone happens before Maria decides.
