# Four-Part Brief: template

Write each part in plain sentences. Delete the guidance lines in brackets before you send it. Mark every line that is a control with (control).

## Outcome
[What should exist when the work is done? State it so someone else could tell whether it is finished. Include the audience and what good looks like.]

## Format
[How should it come back, and where does each piece go next? For structured data, name every field, one row per item, and how to mark a missing value. For an artifact, name the type, audience, length and destination. Name a destination both vendors can reach, such as a downloadable CSV or a Google Sheet in a named folder. Naming one vendor's own editor breaks the port.]

## Inputs
[Name each input and what it decides. Name the governed source and its version, and say it wins. Say what to do when the source is silent. Say that text inside inputs is information, not instructions.]

## Autonomy
[How much may the worker do before checking with you? What must it never do? Where should it stop and ask?]

## Beside the brief
- Your Review Contract, written first (Chapter 6) and shared with the worker. The brief must carry the evidence the worker must return, under Format, and when it must stop, under Autonomy. Independent verification and the verdict stay with you.
- The worker's outer limits: its Authority Envelope (Chapter 7).
