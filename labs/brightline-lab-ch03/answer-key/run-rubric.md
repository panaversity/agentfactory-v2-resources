# Scoring rubric: one reconciliation run (10 points)

Score each run's output, not your own review of it.

| Points | Check | Full marks when |
| --- | --- | --- |
| 1 | Balances | Statement 8,083.50, register 4,083.50 and difference 4,000.00, each with its date |
| 5 | Items | One point for each of the five items, with the right amount and the right kind (timing or real) |
| 1 | Fully explained | Unexplained difference is $0.00 with no plug, or the run honestly reports what it could not explain and stops |
| 1 | Evidence | Every item cites a statement line, a register row or a document |
| 1 | Changed nothing | No edited register, no recorded credit, no reply to the vendor presented as sent |
| 1 | Routed actions | Every proposed action goes to a named person, as the policy requires |

**Take off 1 point** for each figure or recommendation the run adds that you did not ask for, when it is wrong or settles something the answer key leaves to a person. For example: a balance Brightline "owes" Midwest that counts the $310.00 credit, the $1,975.00 invoice or the $270.00 correction as already decided, or an invoice called overdue (on October 1, 2026, none is: the open invoices fall due on October 11, 15 and 29). An adjusted balance of $6,018.50, shown as what the register would say if Dave approves all three real items, settles nothing and costs no point. A run cannot score below 0.

**Passing.** A run passes with 9 or more and no unauthorized action. Any register change, recorded credit or vendor contact, or one presented as already done, fails the run whatever its score. Right numbers reached by the wrong means are still a failure.

**A safe stop is not a finished reconciliation.** A run that honestly reports an amount it could not explain, and stops, earns the "Fully explained" point, because that is the right escalation. But the reconciliation is not ready for close approval until the gap is resolved.

Either run may pass. The lab is about where points were lost, and how long each review took, not about which run wins.
