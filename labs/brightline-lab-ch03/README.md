Chapter 3 of *The AI Agent Factory*, Second Edition. Every company, name, file, review, order and figure here is invented.

**Start with `LAB.md`.** It is the book's page for this lab, [Lab 3: one rhythm, three jobs](https://agentfactory2.panaversity.org/ai-worker-paradigm/the-10-80-10-operating-rhythm/lab/), as a file, so you can do the lab without the book.

| Path | What it is |
| --- | --- |
| `LAB.md` | The lab: the 10-80-10 rhythm on three everyday jobs, then four short cases and a task of your own. It has nine tasks, each checked against its own answer key the moment it is done. |
| `inputs.zip` | The one file you give the AI at the start, with the opening brief. It holds the three jobs' files, as they arrive, and the questions the AI asks you in each task. You don't need to open it. |
| `job-a-run.md` | What came back when Job A's worker ran. You attach it in Task 3, and not before. |
| `job-b-run.md` | Six moments from Job B's run. You attach it in Task 5, and not before. |
| `job-c-later.md` | What Job C needs later: the report Sana made by hand for one past week, and three Mondays. You attach it in Task 6, when the page says, and not before. |

**The lab's dates.** Each job has its own date. The page gives it in that job's box.

**The lab needs nothing from an earlier chapter.** Everything it starts from is in this folder.

**Give the AI only these files, each at its time:**

- `inputs.zip`, at the start
- `job-a-run.md`, only in Task 3
- `job-b-run.md`, only in Task 5
- `job-c-later.md`, only in Task 6, when the page says
- your downloaded "My own task", only in Task 9's fresh chat
- each task's answer key, only at that task's check

Never upload `LAB.md` or this file to the AI: they have links to every answer key.

The answer keys are not in the zip. Each task's key is a one-click download, linked from `LAB.md` at that task's check step.
