# Lab 16 files

These files go with Lab 16 of The AI Agent Factory: the Brightline AP plugin v0.1.

- `brightline-ap/` is a small, working accounts payable toolkit, with no git history, plus the lab's starting files: the six triage rules in `docs/ap-triage-rules.md`, a new batch of invoices in `data/invoices-intake.csv`, the Agent Plugins schemas in `schemas/`, and a practice plugin in `exercises/ap-helper-plugin/`. Task 1 puts it under git.
- Each task's answer key is a separate download, linked from the task in `LAB.md`. Open a key in a text editor only, never in the agent.
- `LAB.md` is a copy of the lab steps.

**Never install, load or run `exercises/ap-helper-plugin/`.** It is a plugin from a stranger, for Task 14 to read. Its script is not executable, and the address it would send data to uses the reserved `.example` domain, so it can never reach a real server.
