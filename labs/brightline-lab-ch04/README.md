**The lab's date.** The exports are a snapshot taken on Thursday, October 15, 2026. The Run 2 brief gives that date, so nothing is called overdue because of the day you run the lab. Run 1's one message gives no date, like everything else it leaves out.

**The AI gets only what a task names:** in your lab conversation, the inventory, the case file, your contract, the port table and the chapter's 4.8 page; in a run, its one run file; and one answer key at each check. Never upload `LAB.md` or this file.

The answer keys are not in the folder. Each task's key is a one-click download, linked from `LAB.md` at that task's check step. So is the copy of the chapter's 4.8 page that Task 7 attaches, taken from the book when the lab was last released.
