# Brightline lab, Chapter 4: The Architecture in One Picture

A standalone lab folder for *The AI Agent Factory*, Second Edition, Chapter 4. It needs no files from other chapters. Every name, address, invoice and figure in it is invented. The exports are a dated snapshot that stands for live systems. The lab tests how an assistant selects evidence, not whether controls block a wrong action.

**The lab's date.** The exports are a snapshot taken on Thursday, October 15, 2026. Your Run 2 brief gives the assistant that date as today's date, so due dates come out the same whenever you run the lab. Run 1's one line gives no date, like everything else it leaves out.

Start with `LAB.md`. It gives every step.

| Folder | What is in it |
| --- | --- |
| `inventory/` | Brightline's AP Worker setup as it stood in the week of October 12, 2026: 16 items |
| `inputs/` | The files for the precedence test: two policy excerpts, memory notes, a vendor-record export, an approvals log, an email |
| `architecture/` | The layer-map template you fill in |
| `results/` | Templates for the precedence test with its port, the swap test and the port table |
| `role/` | The Role Contract template, and a sample Draft 2 for readers who skipped Chapter 3 |
| `answer-key/` | The keys and the rubric. Open them only after you have scored your own work |
