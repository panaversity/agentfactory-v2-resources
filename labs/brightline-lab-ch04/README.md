# Lab 4: map the AP Worker onto the picture

Chapter 4 of *The AI Agent Factory*, Second Edition. Every name, address, invoice and figure here is invented. The exports are a dated snapshot that stands for live systems: the lab tests how an assistant selects evidence, not whether controls block a wrong action.

**Start with `LAB.md`.** It is the book's page for this lab, [Lab 4: map the AP Worker onto the picture](https://agentfactory-v2.vercel.app/ai-worker-paradigm/the-architecture-in-one-picture/lab/), as a file, so you can do the lab without the book.

| Path | What it is |
| --- | --- |
| `LAB.md` | The lab: the job, and eight tasks, each checked against its own answer key. |
| `inventory/current-setup.md` | Brightline's AP Worker setup, week of October 12, 2026: the 16 items you place. |
| `files/` | The six files for the precedence runs: two policy excerpts, memory notes, two accounting exports, one email. Each run attaches only the files its task names. |
| `architecture/` | The layer-map template, with the swap test at its bottom, and the port-table template. |
| `role/` | The Role Contract template, and a sample Draft 2 for readers who skipped Chapter 3. |
| `AGENTS.md`, `CLAUDE.md` | The brief the Claude or ChatGPT desktop app reads if you do the lab with it in this folder. `CLAUDE.md` only points to `AGENTS.md`. |

**The lab's date.** The exports are a snapshot taken on Thursday, October 15, 2026. The Run 2 brief gives that date, so nothing is called overdue because of the day you run the lab. Run 1's one message gives no date, like everything else it leaves out.

**The AI gets only what a task names:** the files a run lists, your pasted document for a check, and one answer key at each check. Never upload `LAB.md` or this file.

The answer keys are not in the folder. Each task's key is a one-click download, linked from `LAB.md` at that task's check step.
