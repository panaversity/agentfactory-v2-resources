## Why

Memory remembers: continuity, preferences, where to look. It is never the authority (4.3). The move is the chapter's wipe test made real: the new vendor's memory is empty, and if the worker was right only because of something it remembered, it is wrong now. On Monday the worker was wrong because of something it remembered: Net 30, learned in July, true until August 14. The vendor record had Net 15. When memory and a record disagree, the record wins, and the fix is not a better memory but a line that sends the worker to the record. Of the four entries, one is a preference and can be learned again at no risk. The other three are facts that belong in a record or in a question to Dave.

## Never a deduction

- Whether memory is called rented, "on the line", or the vendor's: the chapter draws it on the line.
- The exact words that point the worker to the vendor record.
- Where the pointer is written: the Role Contract or the instructions.
