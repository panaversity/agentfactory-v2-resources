# Lab 4 answer key: Task 5. Name the layer it trusted

The answers for Task 5 of Lab 4, in Chapter 4 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** When your diagnosis is written, attach this file in your check conversation, with the lab's check prompt and your diagnosis pasted under it.

## The check

Task 5 carries check 4 of the lab's 11.

4. **Every point lost, in any run, names the layer that was wrongly trusted, and what fixed it.** Memory trusted over the vendor record (Q1). The superseded policy copy, or memory, trusted over the approved version (Q2). Email text trusted as an approval (Q3, the hard rule). Memory's remark trusted as policy (Q4). The runtime's own guess or calendar, for any unasked figure or date. For each point Run 2 won back, the fix is named: a file Run 2 could reach that Run 1 could not, or a line of the precedence brief. A run that lost nothing is diagnosed honestly: say what it rested each answer on. Missed: a loss with no layer named, or "the model was bad" with no source.
