## The checks

Task 4 carries checks 12 to 14 of the lab's 21.

12. **Owned, and carried: the case files, with the run notes in them.** Your section says where the work stands is Brightline's; that the move carries each invoice's case file in the AP shared folder; and that the run notes are copied into the case files before the move, because the chat they were typed in stays behind.
    - Passed: owned, case files carried, run notes moved into them. "Each invoice's file in our folder, and the notes from the chat go in there first" passes.
    - Missed: the run notes left in the shared project's chat, or "rebuilt": the run then answers Dave's question with "lost in the move". Missed too: the notes copied into one run-notes file of their own. That is a log of runs, and the SSoR is one case file per matter (4.4): what happened to 5102 belongs in 5102's file, where the next person who asks about 5102 looks.
13. **The run: 5120 is in Thursday's run, waiting for Dave's approval of the run, from the case file.** The new worker answers Maria that 5120 is under the $5,000 limit, so needs no approval of its own, and sits in Thursday's payment run, which waits for Dave's approval of the run as a whole, and names the case file.
    - Passed: in the run, waiting for the run's approval, from the case file.
    - Missed: "approved by Dave"; or an answer from the register row, which Task 5 puts right; or "lost in the move".
14. **This week: the worker never read the case file, and its own record lived in the vendor's chat.** Your "This week" says that on Thursday the worker answered Maria from the register row it had typed that morning, not from 5120's case file, which was right and kept by hand; and that its own record of the week, the run notes, sat in a chat the company does not own.
    - Passed: both: the case file not read, and the run notes in the chat. Plain words pass.
    - Missed: the case file blamed; or no cause named.

## Why

The SSoR tracks where the work stands: one case file per matter, what was tried, who approved what, and why (4.4). Brightline had that for 5120, kept by hand by Maria, and the worker never read it. What the worker wrote, its run notes, went into a chat window, the one place on the list that no move carries and no colleague can open. The move makes the loss plain: ask the new worker what happened to 5102 last week and, unless the notes were moved into the case files, nothing it has says. A record of the work belongs with the work, in a file the company owns, where the next worker, and the next person, can read it.

## Never a deduction

- The register spreadsheet named here as well as in Task 5.
- Whether the notes go into the case files by hand or by the worker: the page says they go there.
