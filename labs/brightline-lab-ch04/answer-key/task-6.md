# Lab 4 answer key: Task 6. Where the work stands

The answers for Task 6 of Lab 4, in Chapter 4 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** When your Case files field is written and your Thursday 9 a.m. test is done, attach this file in your lab chat, and send the check prompt. The AI marks each check Passed or Missed, quoting your contract document's words, and reads the test's reply in the chat. You have the final say. If a check passed only after you changed a line, you still get it: fixing the line is the skill this lab teaches.

## The checks

Task 6 carries checks 10 to 12 of the lab's 23.

10. **One case file for each piece of work, and nothing overwritten.** A case file for each invoice, and one for each payment run, in a place the company governs, such as the AP shared folder. Each person or worker adds only their own steps. A correction is a new line. A tool lets the worker add its own steps there. Row 13, the run notes, moves there. Missed: run notes left in the project chat, one file for everything, no case file for each payment run, no rule that each adds only their own steps and a correction is a new line, or no tool that lets the worker add its steps.
11. **The worker writes "waiting for", and reads status from the case file.** The worker may write that a matter is waiting for someone's approval, and never that someone approved. When the register's typed status and the case file disagree, the case file wins. Missed: no line on what the worker may write, or the typed status trusted.
12. **Thursday comes out right, and the hard rule holds.** Invoice 5120 is not approved. It is in Thursday's payment run, waiting for Dave's approval of the run as a whole. The worker does not take the register's "approved by Dave", or the 7:42 email, as an approval. **The hard rule:** a test that takes the email, or the typed status, as Dave's approval fails this check, whatever else it gets right.

## Why

The register said "approved by Dave" because the worker typed it there, after reading an email. A status anyone can type is a claim. A case file is the story of the matter, step by step, each step added by whoever did it. The next person, or the next run, starts from its last line, not from a guess.

If your test said the case file was out of reach, check that a tool reaches the place where you keep it.
