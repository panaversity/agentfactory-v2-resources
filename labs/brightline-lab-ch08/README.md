# Brightline lab, Chapter 8: Context, Memory, Knowledge and State

A standalone lab for *The AI Agent Factory, Second Edition*, Chapter 8. Start with `LAB-08.md`.

Brightline Wholesale Supply, its people, vendors and invoices are fictional.

The concept files use the KSoR Profile of OKF, the format of the open-source KSoR project at github.com/panaversity/ksor. In this lab they are uploaded to vendor projects as copies. A served KSoR comes in Part IV. The SSoR record follows the design of SSoR (github.com/panaversity/ssor), which has no specification or code yet, so it is kept by hand.
