**Three situations.**

- **A. Restart.** The task is done. A new conversation in the same project starts with the instructions and concepts, without last week's detours.
- **B. Summarize.** The task continues, but old turns now mislead. Ask for a handover note of settled and open purchases, check it against your own list, and start a new conversation from it.
- **C. Persist.** A rule typed into every chat belongs in the project instructions. If it is really policy, draft a concept and ask Dave to approve it.
