# Lab 8 answer key: Task 3. What memory may keep

The answers for Task 3 of Lab 8, in Chapter 8 of *The AI Agent Factory*, Second Edition. Every name, number and company in this lab is invented.

**How this key is used.** When "Memory audit" in "Maria's records" has your decision for each topic and your two answers, and `Test: Buckeye` is back, attach this file in your lab chat, and send the check prompt. The AI marks each check Passed or Missed, quoting your documents' lines and the test's reply in the chat. You have the final say. If a check passed only after you changed a line, you still get it: fixing the line is the skill this lab teaches.

## The checks

Task 3 carries checks 6 and 7 of the lab's 40.

6. **What memory keeps, and the audit.**
   - Topic 4, "Brightline's approval threshold is $10,000", is deleted, because the limit lives in the approved policy, section 4.1, which says $5,000. It is gone from "Memory" in the "AP Worker project" document.
   - Topics 2, 3 and 5 are kept: they are how Maria likes the work done. Topics 1 and 6 may be kept or deleted: they hold no rule, amount or status.
   - Memory is read again on a set day, such as the first Monday of each month, and after any answer that surprises you. Each time, the date and what was deleted are written down.
   - Passed: all three.
   - Missed: topic 4 kept, or rewritten as $5,000; topic 2, 3 or 5 deleted; or an audit with no set day, no reading after a surprising answer, or nothing written down.
7. **Memory kept apart, and the test.**
   - Claude: each project keeps its own memory. ChatGPT: choose project-only memory, when the project is made.
   - `Test: Buckeye`: invoice BO-23104, $6,150.00, is over $5,000.00, so it needs Dave's approval before payment, from the policy, section 4.1.
   - **The hard rule.** A test that accepts $10,000 as Brightline's threshold fails this check, whatever else it gets right.
   - Passed: both vendors as above, the test as above, and the hard rule holds.
   - Missed: a vendor's answer missing or wrong; the test answering "no approval needed"; or the hard rule broken.

## Why

Memory is written by the product from what was said, and nobody approves it (Lesson 8.4). A remark about next year became a rule. So memory gets a narrow job: preferences and how you work. Anything a decision depends on stays out: policy, limits, amounts, statuses. New topics keep arriving, so one reading is not enough: read it on a set day, and again after any answer that surprises you, because a surprise is often memory at work (Lesson 8.4). Each time, write down what went. A project should also keep its memory apart from your other work. Claude does that by itself. ChatGPT does it once you choose project-only memory, which you choose when you make the project (Lesson 8.8).

## Never a deduction

- A different set day, such as every Friday, when it is a set day.
- The test adding that Dave approves the whole run as well (4.3).
- The test noting that no instruction line yet says which source counts.
- A remark about the lab's dates.
