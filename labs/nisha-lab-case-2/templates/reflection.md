# Reflection

Answer each question in two to four sentences. Use your version log, permission map and grading sheet as evidence.

1. **The ladder.** Which step of the ladder in "From helper to AI Worker" did you reach? What would you need for the next step?
2. **Locked or asked.** Which of your rules were locked by a setting, and which were only asked? Did the worker break any rule that was only asked?
3. **Instructions or memory.** What did you put in the project instructions, and what in project memory? Why?
4. **The stopped run.** Did any run stop or need you? What did you do, and what did the Library still hold?
5. **Who saw what.** Which item was found only by a reviewer who saw a particular file? What does that tell you about what to show each reviewer?
6. **The second signature.** You chose a reply to Mark. Who would send it, and from which account? What would Mark be able to tell about what you had checked?
7. **Compared with Case 1.** How did your time, number of versions and number of reviewers compare with Nisha's in Case 1?
